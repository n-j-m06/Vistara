# 🇮🇳 Vistara — Explore India, Experience Infinity

Vistara is a cinematic full-stack tourism discovery platform designed to digitally showcase the beauty, culture, heritage, spirituality, and diversity of India through an immersive modern web experience.

Built with a premium UI philosophy and scalable backend architecture, Vistara enables users to explore Indian states and union territories through dynamic tourism pages, category-based discovery, smart filtering, ambient experiences, and admin-controlled content management.

---

# ✨ Features

## 🌍 Tourism Discovery Platform
- Explore Indian states & union territories
- Dedicated cinematic state pages
- Famous places, cuisine, culture & travel highlights
- Official tourism website integration

# 🚀 Getting Started

## Clone Repository

```bash
git clone <your-repo-link>
```

---

# ⚙️ Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

# ⚙️ Backend Setup

```bash
cd backend

npm install

npm run dev
```

Backend runs on:

```bash
http://localhost:5000
```

---

# 🌐 Environment Variables

Create `.env` inside backend:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```
